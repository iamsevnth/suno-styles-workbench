# History, Persistence & Offline Build

## 16.1 Session Persistence & History Schema (persist-history.ts)
Suno Workbench persists your work locally inside your browser without ever transmitting
prompts or lyrics to an external database. In src/lib/suno/persist-history.ts and the main
application state, session history is stored in localStorage under versioned keys and can be
exported at any time to disk:

     TypeScript Interface — HistoryEntry & Export Utilities (src/lib/suno/persist-history.ts)
     export interface HistoryPrompt {
       variant: number;
       title: string;
       styles: string;
       charCount: number;
       bpm: number;
       genres: [string, string, string];
     }

     export interface HistoryEntry {
       id: string;
       createdAt: string;     // ISO-8601 timestamp
       brief: string;     // Raw user input brief
       seed: number;         // 32-bit unsigned PRNG seed for exact replay
       prompts: HistoryPrompt[]; // All 3 compiled variants
     }
