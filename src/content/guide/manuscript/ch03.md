# Creative Brief Syntax & Parsing

## 3.1 How parseUserInput() Deconstructs a Creative Brief
Stage 1 of the Suno Workbench compiler lives in src/lib/suno/parse.ts (export function
parseUserInput(raw: string): ParsedInput). Unlike naive keyword splitters, parseUserInput()
executes an 8-step deterministic lexical analysis pipeline that sanitizes forbidden tokens, extracts



tempo and vocal directives, resolves multi-word genres longest-first, expands mood adjectives,
and classifies remaining tokens into instruments, production cues, and arrangement notes.

    TypeScript Interface — ParsedInput (src/lib/suno/types.ts)
    export interface ParsedInput {
        raw: string;
        isEmpty: boolean;
        genres: string[];        // Canonical genre names matched from Ontology + Atlas
        bpm?: number;              // Integer BPM clamped to [60, 200] (last mention wins)
        moods: string[];          // Canonical mood tokens + MOOD_MAP expansions
        instruments: string[];      // Matched instrument phrases
        production: string[];      // Matched production, drum, bass, and mix cues
        arrangement: string[];       // Matched structural arc cues
        vocalGender?: 'female' | 'male' | 'duet' | 'none' | 'chops';
        vocalStyle: string[];     // Intimate, breathy, rap, belting, etc.
        strippedArtists: string[]; // Artist names caught and converted to sonic equivalents
        convertedNegations: string[]; // Negative clauses rewritten to positive equivalents
    }

                                     Carti, Central Cee, Pop Smoke, RL Grime, Subtronics, Rezz, Illenium)
                                     or 'in the style of / type beat' phrase is stripped and replaced with its
                                     pure acoustic production equivalent.

    Step 2: Negation-to-             Matches negative constructions ('no vocals', 'without drums', 'no
    Positive Rewriting               harsh highs', 'avoid muddy bass', 'not cheesy', 'no rap', 'without
                                     guitar') and rewrites them into positive acoustic directives (e.g., 'no
                                     harsh highs' -> 'warm controlled high frequencies with smooth roll-
                                     off'; 'no muddy bass' -> 'tightly carved low-mid pocket with clean sub
                                     separation').

    Step 3: Integer BPM              Scans for explicit numbers followed by 'bpm' or standalone 2-to-3
    Extraction (Last-Wins            digit numbers in [60, 200]. If a brief contains multiple numbers (e.g.,
    Rule)                            'starts at 90 bpm then drops at 140 bpm'), the parser takes the LAST
                                     valid match (matches[matches.length - 1]), rounds it to an integer,
                                     and clamps it to Math.max(60, Math.min(200, bpm)).

    Step 4: Vocal Mode &        Detects explicit instrumental flags ('instrumental', 'no vocals', 'beat

    Step 6: Longest-First       Iterates through genreNamesLongestFirst() (all 259 genres sorted by

                                or '140 UKG' matches as a single specific genre before 'Trap' or 'UKG'

    Disambiguation Rules        an atmospheric mood unless explicitly paired as 'ritual bass' or 'ritual

                                'ukg', 'uk garage', or 'uk bass'.

                                ['dark', 'shadowy', 'nocturnal', 'ominous']; 'euphoric' expands to
                                ['euphoric', 'soaring', 'luminous', 'wide-screen']).
