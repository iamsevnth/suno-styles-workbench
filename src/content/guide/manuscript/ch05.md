# Genre Atlas & Blend Architecture

## 5.1 How the Blend-Band Engine Replaces Arbitrary Randomness
A common failure mode of naive 'random style generators' is combining incompatible genres
without structural mediation—producing prompts that confuse Suno into muddy chaos. In
src/lib/suno/genre-atlas.ts, Suno Workbench implements a graph-based cluster topology across
15 acoustic clusters (CLUSTER_OF) governed by three Blend Bands: 'tame', 'weird', and
'unhinged'.

     DESIGN RULE — BLEND BANDS HONOR NAMED COLLISIONS FIRST
     As documented at the top of src/lib/suno/genre-atlas.ts: 'Tame / weird / unhinged is a
     BLEND BAND, not a mandatory UI slider. Inferred from the brief. Named collisions (e.g.,
     gospel dubstep, bluegrass trap, opera drill) are ALWAYS honored verbatim.'
     When a user explicitly names two distant genres in their brief, the compiler preserves both
     as Primary and Secondary anchors and automatically infers the appropriate blend band so
     the supporting arrangement and mix glue bridge the collision cleanly.




## 5.2 The 15 Acoustic Clusters & Adjacency Matrices
Every genre in the 259-style universe maps via clusterOf(genreName) to one of 15 macro-
clusters. Distance between any two genres is computed by blendDistance(a, b) using two
adjacency maps: TAME_NEIGHBORS (distance = 1) and WEIRD_NEIGHBORS (distance = 2). Any



pair not in the same cluster (distance = 0), TAME_NEIGHBORS (distance = 1), or
WEIRD_NEIGHBORS (distance = 2) has a collision distance of 3 ('unhinged').

## 5.3 Automatic Blend-Band Inference (inferBlendBand)
When the user leaves Blend Mode set to 'Auto', inferBlendBand(parsedGenres, rawBrief) inspects
both the lexical markers in the brief and the maximum cluster distance between any user-named
genres:

   Unhinged Band (Distance = 3): Triggered if the brief contains explicit keywords ('unhinged',
    'cursed', 'chaotic', 'wtf', 'collision', 'mashup', 'fever dream') OR if the user names two genres
    whose blendDistance is 3 (e.g., 'Bluegrass + Cyber Riddim' or 'Gregorian Chant + Baile Funk').
   Weird Band (Distance = 2): Triggered if the brief contains keywords ('weird', 'experimental',
    'hybrid', 'fusion', 'cross', 'unexpected', 'left-field') OR if the user names two genres whose
    blendDistance is 2 (e.g., 'Gospel + Deep Dubstep' or 'Shoegaze + Trap').
   Tame Band (Distance = 0 or 1): Default when user genres share the same cluster (distance =
    0) or adjacent clusters (distance = 1, e.g., 'Future Bass + Trap + 140 UKG'). Keeps donor
    selection inside cohesive neighborhood boundaries.
