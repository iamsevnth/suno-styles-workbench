# Suno Workbench v5.3.1 — Guide Title Case and Official Offline Sync

v5.3.1 is a documentation and packaging patch on top of v5.3.0. It does not change Styles generation, the Prompt Fidelity Inspector rules, Lyrics Studio arrangement, privacy model, or network behavior.

## Why this patch

The immutable [v5.3.0](https://github.com/iamsevnth/suno-styles-workbench/releases/tag/v5.3.0) GitHub Release was published from commit `120938c`. Three subsequent `main` commits applied Title Case to the Guide page hero, search label, and verified chapter section headers. Because the v5.3.0 release publisher refuses to overwrite existing assets, the standalone HTML download lagged `main`.

## Included changes

- **Guide UI Title Case:** Hero title and search label on `/guide` use headline case consistent with the rest of the site.
- **Verified Guide chapters:** Section headers in `current-workbench`, `create-mode`, `fidelity-inspector`, `lyrics-arranger`, and `reconciliation` use Title Case.
- **Official offline package:** Publishes a new immutable tag **`v5.3.1`** with rebuilt standalone HTML and SHA-256 checksum that match the patched Guide content.
- **Documentation alignment:** README, CONTRIBUTING character-window guidance, Guide download pointers, and the release workflow contract are updated to **5.3.1**.

## No feature expansion

Compiler algorithms, fidelity detectors, Lyrics Studio provenance checks, CSP rules, and browser-storage behavior are unchanged from v5.3.0.

## Official v5.3.1 Download Package

The official GitHub Release uses tag **`v5.3.1`** (matching the application package version) and title **`suno-workbench-sevnthlabs-v5.3.1`**.

Release download assets:

- **`suno-workbench-sevnthlabs-v5.3.1.html`** — the complete self-contained offline edition rebuilt from the validated `main` commit that includes the Title Case Guide fixes.
- **`suno-workbench-sevnthlabs-v5.3.1.html.sha256`** — SHA-256 checksum for verifying the downloaded HTML.

The asset is rebuilt with TypeScript checking, the full test suite, the Vite/site build, and the offline CSP verifier. The release workflow checks package and lockfile versions, Guide files, output size, and checksum before uploading. It refuses to overwrite existing release assets on subsequent runs.

**How to use:** Download the `.html` asset from [GitHub Releases](https://github.com/iamsevnth/suno-styles-workbench/releases/tag/v5.3.1), save it locally, and open it in a modern desktop browser.

**Verify integrity (optional):** Place the HTML and `.sha256` in the same folder, then run `sha256sum -c suno-workbench-sevnthlabs-v5.3.1.html.sha256` (Linux) or `shasum -a 256 suno-workbench-sevnthlabs-v5.3.1.html` and compare the value with the checksum file (macOS).

## Validation

- TypeScript compilation, full regression suite (including Guide and release packaging contracts), hosted and offline builds, CSP verification.
- Dependency review and CodeQL remain required on pull requests.

## Known limitations

Unchanged from v5.3.0: lexical fidelity detection is not semantic or audio evaluation; Lyrics Studio never invents lyric words; Workbench character targets are application rules, not Suno-certified optima.
