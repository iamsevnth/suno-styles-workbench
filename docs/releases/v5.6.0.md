# Suno Workbench v5.6.0 — Instrumental Toggle

## Added

- **Instrumental** toggle in the brief panel, next to Hybrid Bass Profile (Create mode; off by default; kept for the session).
  - **On, and the brief never mentions vocals:** the prompts stay instrumental. No singer, rapper or vocal line is added, and the prompt checks reject vocal wording, so On-Device AI rewording can't add one either.
  - **On, and the brief mentions vocals in any form** (a singer, rap, a voice, vocal chops, a choir, a male or female lead, lyrics, ad-libs): the brief wins and the vocals are kept. A note under the brief says the toggle doesn't apply.
  - "No vocals", "without singing" and other exclusions don't count as a mention.
  - **Off:** generation is exactly as in v5.5.0.
- History entries record the toggle's state.

Fix Existing Prompt mode is unchanged: it rewrites the prompt you paste, so the toggle isn't shown there.
