# Suno Workbench v5.4.1 — Brief Check Accuracy

v5.4.1 makes six Brief Check notes more precise, from the follow-up review of v5.4.0. **Styles generation is unchanged.**

## Fixed

- **`TOO_MANY_EQUAL_GENRES`:** a role counts only when a genre word names it ("trap groove", "future bass chords"). Unrelated phrases such as "syncopated drums, vocal hook" no longer hide the note.
- **`MASSIVE_FULL_RANGE_BASS_STACK`:** a bass source counts as separate only when its own phrase assigns it a section ("reese in the first drop") or a call-and-answer role. A section word nearby ("growl bass under a vocal chorus") no longer hides the stack.
- **`UNDEFINED_HOOK`:** briefs without a native route (e.g. "surprise me") are classified by their genres, so a folk or acoustic brief never gets the electronic hook note. "Melodic" in a genre name ("melodic dubstep") no longer counts as a hook; "melody" still does.
- **`ELECTRONIC_HATS_EXCLUDED`:** any hat request ("crisp hi-hats") conflicts with excluding all hats. Exclusions are now read up to the next comma, so the rest of the brief after "no …" still counts.
- **`TWO_PRIMARY_KICK_SYSTEMS`:** bare "UKG" is read as UKG Dubstep (half-time), matching the parser; only "UK garage", "garage shuffle" or an explicit "2-step" counts as a 2-step kick.
